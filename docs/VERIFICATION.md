# Verification for version 3.1

This release adds nested JSON-LD reference resolution, scoped microdata/RDFa and business subtypes, readable company-description fallback, explicit inline recruitment advertisements and linked public Greenhouse/Lever boards. The research viewer now presents cited business-question briefs, financial cards, six topic tabs, readable facts, hiring relationships and a dated activity timeline. It retains search, comparison, evidence inspection and export.

155 regression tests ran: 154 passed and one optional rendering test was skipped. Consequential new cases cover nested scopes and source spans, itemref ownership, RDFa identity, boilerplate exclusion, inline advertisement requirements/expired ads, real website-to-board-to-API acquisition with wrong-tenant/prospect rejection, derived-metric currency/period gates and summary citation validation.

The current runtime was exercised offline against responses captured by our previous 100-company live run. All 100 completed with zero company errors; all 15 verified websites and 10 companies with public profiles were retained. Company descriptions increased from 12 to 14 and companies with an observed job advertisement from zero to one. The recovered inline advertisement is labelled as an observation, with no invented publication date or confirmed current status. All source hashes, verbatim spans, summary citations and output aliases passed validation. Six new URLs were unavailable in the saved response set. This replay measures extraction/integration on existing captures; it is not a fresh live benchmark or an independent accuracy estimate.

The viewer passed a separate headless browser check using all 100 profiles: six tabs, period selection, sorting, comparison, evidence dialog and exact quotes, keyboard navigation, search, selected-company JSONL export, cited answers, deep links, desktop and all mobile topic layouts without page overflow, and dark mode. No JavaScript errors were recorded. Desktop and mobile screenshots were visually inspected.

The focused live run re-fetched VEXTI's public website and recovered its inline carpenter advertisement with the required role, qualifications and application instruction. It completed with zero company errors in 21 outbound requests. All 19 captures passed hash/span/citation checks. The advertisement has an observation date and explicitly unconfirmed direct-employer/current-status semantics.

The source package is checked in an extracted folder with Python -S and network access blocked. Both bundled-cache and missing-custom-cache fixture modes emit a completed, evidence-valid terminal envelope. Required candidate assets, hash-pinned trust data and licence notices are checked against their manifests. The package excludes research, run outputs, private inputs and credentials. Detailed results and runtime hashes are recorded in verification.json.

The previous version 3.0 fresh 100-company smoke remains the latest full live cohort: 100 completed, zero company errors, 15 websites, 10 companies with 14 public profile links, seven company publications, and no hiring claims, using 1,308 requests in 294.859 seconds. Those timing/coverage figures belong to 3.0. The current release has the saved-source integration above and a focused live check; they must not be presented as a new 100-company live run.

The observed-domain index remains an initial 160-host acquisition with 10 exact-owner candidate pairs, independently reverified at runtime. Brand discovery, social coverage, unsupported job formats and JavaScript-only sources remain incomplete. The 1,000-company scale check has not run. No local test establishes official qualification, factual precision/recall, ranking, or guaranteed execution on inaccessible sources or filesystems.
